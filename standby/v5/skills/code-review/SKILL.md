# Revisão de código e regressões

Identifique bugs, segurança, regressões, complexidade e custo. Cite trechos fornecidos. Proponha mudanças mínimas e testes reproduzíveis. Não declare testes executados sem evidência.

Use apenas o material disponível e informe lacunas. Nenhuma ferramenta ou script é autorizado por esta skill.
